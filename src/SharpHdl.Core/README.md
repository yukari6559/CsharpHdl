# SharpHdl.Core

C# DSL for describing synchronous digital hardware (modules, signals, comb/seq logic, memory primitives).

Use with [SharpHdl.Emit](https://www.nuget.org/packages/SharpHdl.Emit) to generate Verilog.

## Install

```xml
<PackageReference Include="SharpHdl.Core" Version="0.5.0" />
```
